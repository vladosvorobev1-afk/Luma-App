# 🧠 Luma

**Luma** — Android-приложение для ментальных тренировок (тревога, сон, прокрастинация, стресс, фокус). 
Проект создан как демонстрация навыков современной Android-разработки для Junior-позиции.

## 🛠 Стек технологий
- **Язык:** Kotlin 1.9.24
- **UI:** Jetpack Compose, Material Design 3
- **Архитектура:** MVVM + Repository
- **Сеть:** Retrofit, OkHttp, Kotlinx Serialization
- **Локальное хранилище:** Room (Cache-first), DataStore
- **Фон и уведомления:** WorkManager, Deep Links
- **Мультимедиа:** TTS (Text-to-Speech)
- **Тестирование:** JUnit 4, Mockk (31 Unit-тест)

## 🚀 Ключевые особенности реализации
1. **Cache-first архитектура:** Сначала данные из Room, затем из сети (Retrofit), с fallback на локальные данные.
2. **Статистика и Стрик (Streak):** Сложный SQL-запрос для подсчета активных дней. Логика подсчета серии вынесена в чистую функцию и покрыта 8-ю юнит-тестами.
3. **Deep Links из уведомлений:** При клике на Push-уведомление открывается сразу экран конкретного упражнения, минуя главный.
4. **Управляемая тема:** System / Light / Dark через DataStore.
5. **Озвучка (TTS):** ProcessLifecycleOwner останавливает воспроизведение при уходе в фон.

## 🧪 Тестирование
Проект покрыт 31 Unit-тестом (JUnit + Mockk):
- Мапперы DTO ↔ Domain (13 тестов).
- Обработка сетевых ошибок (10 тестов).
- Логика подсчета Streak (8 тестов).
